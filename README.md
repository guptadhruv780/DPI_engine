## 📖 About The Project

In modern network security, traditional firewalls are often not enough because they only look at IP addresses and port numbers. This **Deep Packet Inspection (DPI) Engine** acts as an advanced network sentry. Instead of just looking at the "envelope" of internet traffic, it opens the envelope and reads the "letter" inside. 

By analyzing the actual data payload (like TLS Handshakes and HTTP Headers) inside the packets, this engine can accurately identify exactly which application (e.g., YouTube, Netflix, Facebook) is generating the traffic, regardless of the port being used.

### 🎯 Core Objectives:
1. **Visibility:** Provide deep insights into network traffic by breaking down raw `.pcap` files.
2. **Control:** Allow network administrators to block specific apps, domains, or IP addresses dynamically.
3. **Security:** Automatically flag network anomalies and suspicious packet patterns.

## ⚙️ How It Works (Architecture)

1. **Packet Ingestion:** The engine reads raw network capture files (`.pcap`) generated by tools like Wireshark or `tcpdump`.
2. **Protocol Parsing:** Using the `Scapy` library, it strips away Ethernet and IP layers to access the TCP/UDP transport layers.
3. **Deep Payload Extraction:** 
   - For HTTPS traffic, it extracts the **TLS Server Name Indication (SNI)** from the ClientHello handshake.
   - For HTTP traffic, it extracts the `Host` header.
4. **Classification & Filtering:** The extracted domain/SNI is matched against an internal database of Application Signatures (e.g., `googlevideo.com` = YouTube). It then checks the active Block Rules to determine if the packet should be *Forwarded* or *Dropped*.
5. **Real-time Streaming:** The backend uses `FastAPI` and `WebSockets` to stream the analysis results live to the web dashboard.

## 🛠️ Local Installation & Setup

Want to run the DPI Engine on your own machine? Follow these steps:

### Prerequisites
- Python 3.11 or higher
- Git

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/guptadhruv780/DPI_engine.git
   cd DPI_engine
   ```

2. **Create a Virtual Environment:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r dpi-engine-python/requirements.txt
   ```

4. **Run the Server:**
   ```bash
   cd dpi-engine-python
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

5. **Access the Dashboard:**
   Open your browser and navigate to `http://localhost:8000`.
